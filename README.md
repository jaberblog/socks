# مدیریت جین جوراب (JeanSockManager)

اپلیکیشن اندرویدی مدیریت و محاسبه سود جین جوراب با کاتلین و Jetpack Compose مطابق طرح فیگما.

## راهنمای ساخت خروجی APK با GitHub Actions
1. فایل‌های داخل این زیپ را در یک ریپازیتوری جدید در گیتهاب آپلود (Push) کنید.
2. وارد تب **Actions** در ریپازیتوری گیتهاب خود شوید.
3. ورک‌فلو **Build Debug APK** به صورت خودکار اجرا می‌شود (یا می‌توانید با دکمه **Run workflow** آن را دستی اجرا کنید).
4. پس از اتمام ساخت، از بخش **Artifacts** فایل `JeanSockManager-debug-apk` را دانلود کنید که شامل فایل نصبی `app-debug.apk` است.
